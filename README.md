# ⏳ New Year Countdown Timer

A responsive New Year Countdown Timer developed using **HTML, CSS, and JavaScript**. It dynamically displays the remaining days, hours, minutes, and seconds until the upcoming New Year.

## 🚀 Features

- Displays the remaining days, hours, minutes, and seconds.
- Automatically updates the countdown every second.
- Dynamically calculates the upcoming New Year.
- Responsive design for different screen sizes.
- Attractive background image and typography.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 JavaScript Concepts Used

- DOM Manipulation
- Date Object
- `getFullYear()`
- `setInterval()`
- `Math.floor()`
- Time Difference Calculation
- Conditional (Ternary) Operator

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. The countdown will automatically display the remaining time until the next New Year.

## 🎯 Project Objective

The objective of this project is to strengthen JavaScript fundamentals by implementing date and time calculations, DOM manipulation, and real-time countdown functionality.
